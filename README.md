# BankSphere

A fintech banking backend system built with Node.js, Express, and MongoDB.

## Features
 User registration and login with JWT authentication
 Account management with secure financial data endpoints
 Transaction data modeling for debit/credit operations
 Standardized API response and error handling

## Tech Stack
 Node.js, Express.js
 MongoDB
 JWT, bcrypt
 REST APIs

## BAckend Live URL: 
https://banksphere-role-based-internal-banking.onrender.com

## Setup
1. Clone the repo
2. Run `npm install`
3. Add `.env` with MongoDB URI and JWT secret
4. Run `npm start`
